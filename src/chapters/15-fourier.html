Fourier primer: the maths you need

Precursor mathDeck 07, 08

Complex numbers and Euler's formula

A complex number \(z = a + ib\) is a point in the plane. It has a size \(|z| = \sqrt{a^2+b^2}\) and an angle \(\phi\).

\[ e^{i\theta} = \cos\theta + i\sin\theta \]

\(e^{2\pi i \mu t}\) as \(t\) runs = a point spinning around the circle \(\mu\) times per unit time. That is a complex sinusoid with frequency \(\mu\).

Any signal is a sum of sinusoids

A periodic signal with period \(T\) can be written as a Fourier series:

\[ f(t) = \sum_{n=-\infty}^{\infty} c_n e^{2\pi i n t/T}, \qquad c_n = \frac1T\int_0^T f(t)\,e^{-2\pi i n t/T}\,dt \]
  • \(c_0\) = average value (the "DC" term).
  • Low \(n\): slow, smooth variation. High \(n\): fine detail, sharp edges, noise.
  • Example: \(f = 1 + 3\cos t + \sin 2t\) has \(c_0 = 1\), \(c_{\pm1} = 3/2\), \(c_2 = -i/2\), \(c_{-2} = i/2\).

The Fourier transform

For a non-periodic signal, frequencies become continuous:

\[ F(\mu) = \int_{-\infty}^{\infty} f(t)\,e^{-2\pi i\mu t}\,dt, \qquad f(t) = \int_{-\infty}^{\infty} F(\mu)\,e^{2\pi i\mu t}\,d\mu \]

\(F(\mu)\) says "how much of frequency \(\mu\)" is in \(f\). It is complex: size = amount, angle = phase (shift).

\(\mathrm{sinc}(x) = \sin(\pi x)/(\pi x)\). Zeros at \(\mu = k/W\).

The big pattern: wide ↔ narrow. A wide box has a narrow sinc, and the reverse. A Gaussian of width σ transforms to a Gaussian of width \(1/(2\pi\sigma)\). An impulse \(\delta\) (zero width) transforms to the constant 1 (infinite width).

Convolution theorem is the key one: blurring (convolution) becomes simple multiplication in frequency. Example: box * box = tent, so tent ↔ \(\mathrm{sinc}^2\).

Sampling and aliasing

Sampling every \(\Delta T\) = multiplying by an impulse train. In frequency, that makes copies of \(F\) every \(1/\Delta T\):

\[ \tilde F(\mu) = \frac{1}{\Delta T}\sum_n F\Big(\mu - \frac{n}{\Delta T}\Big) \]
  • Nyquist: if \(f\) has no frequency above \(\mu_{\max}\), sample faster than \(2\mu_{\max}\). Then copies don't overlap and \(f\) can be rebuilt exactly (ideal low-pass = sinc interpolation).
  • Too slow → copies overlap → high frequencies pretend to be low ones: aliasing (moiré, jaggies).
  • Fix: low-pass filter before sampling (or before shrinking an image).

The discrete Fourier transform (DFT)

\[ F[u] = \sum_{x=0}^{M-1} f[x]\,e^{-2\pi i ux/M}, \qquad f[x] = \frac1M\sum_{u=0}^{M-1}F[u]\,e^{2\pi i ux/M} \]
  • Both \(f\) and \(F\) are treated as periodic with period \(M\).
  • Convolution theorem holds for circular convolution (wraps around).
  • Naive cost \(O(M^2)\). FFT splits into even/odd halves recursively: \(O(M\log M)\).

Worked: f = [1, 2, 3, 4]

\(e^{-2\pi i/4} = -i\). So \(F[u] = \sum f[x](-i)^{ux}\).

  • \(F[0] = 1+2+3+4 = 10\) (sum = DC)
  • \(F[1] = 1 + 2(-i) + 3(-1) + 4(i) = -2 + 2i\)
  • \(F[2] = 1 - 2 + 3 - 4 = -2\)
  • \(F[3] = -2 - 2i\) (= conjugate of \(F[1]\), since \(f\) is real)

The 2D Fourier transform

Same idea as 1D: write the image as a sum of waves. In 2D each wave is a ripple across the image.

\[ F(\mu,\nu) = \iint f(t,z)\,e^{-2\pi i(\mu t + \nu z)}\,dt\,dz, \qquad f(t,z) = \iint F(\mu,\nu)\,e^{2\pi i(\mu t + \nu z)}\,d\mu\,d\nu \]

Discrete (image of M × N pixels):

\[ F[u,v] = \sum_{x=0}^{M-1}\sum_{y=0}^{N-1} f[x,y]\,e^{-2\pi i(ux/M + vy/N)}, \qquad f[x,y] = \frac{1}{MN}\sum_{u}\sum_{v} F[u,v]\,e^{2\pi i(ux/M + vy/N)} \]
  • Direction of \((u,v)\) = which way the wave goes. Length \(\sqrt{u^2+v^2}\) = how fast it wiggles (its frequency).
  • Separable: \(e^{-2\pi i(ux/M+vy/N)} = e^{-2\pi iux/M}\,e^{-2\pi ivy/N}\). So do a 1D DFT on every row, then a 1D DFT on every column of the result.
  • 2D box (size T × Z, height A) ↔ \(ATZ\,\text{sinc}(\mu T)\,\text{sinc}(\nu Z)\). A separable function has a separable transform.
  • Sampling in 2D: no aliasing if \(\Delta T \le \frac{1}{2\mu_{\max}}\) and \(\Delta Z \le \frac{1}{2\nu_{\max}}\). Same Nyquist rule, once per axis.
  • Pixel spacing \(\Delta t\) ↔ frequency range \(1/\Delta t\). Image size \(T = M\Delta t\) ↔ frequency spacing \(1/T\).

Reading the spectrum of an image

\(F[u,v]\) is complex: \(F = |F|\,e^{i\phi}\). \(|F|\) is the spectrum (magnitude), \(\phi\) is the phase. We look at pictures of \(|F|\).

  • Centre = \(F[0,0]\) = the DC term = sum of all pixels = \(MN \times\) mean. Usually the biggest value by far.
  • Near the centre: slow changes (smooth areas). Far from the centre: fast changes (edges, fine texture, noise).
  • A repeating stripe pattern gives a pair of bright dots at \(\pm(u,v)\).
  • An edge or line gives a bright line through the centre, at 90° to the edge.
  • Real image ⇒ \(F[-u,-v] = F[u,v]^*\). So \(|F|\) is symmetric about the centre (that is why the dots come in pairs).
  • Real and even \(f\) ⇒ \(F\) real and even. Real and odd ⇒ \(F\) imaginary and odd.
  • Energy is the same in both domains (Plancherel): \(\sum|f|^2 = \frac{1}{MN}\sum|F|^2\).

How the picture is made

  1. The DFT puts frequency 0 in the corner. Multiply \(f[x,y]\) by \((-1)^{x+y}\) before the DFT to move it to the centre (same as fftshift, for even M, N).
  2. Show \(\log(1 + |F|)\). Without the log, DC is so bright that everything else looks black.

Shift, rotate, and why phase matters

\[ f[x-x_0,\ y-y_0] \;\Longleftrightarrow\; F[u,v]\,e^{-2\pi i(ux_0/M + vy_0/N)} \]
  • Shift the image: \(|F|\) does not change at all. Only the phase changes (by \(-2\pi(ux_0/M+vy_0/N)\)).
  • So where things are is stored only in the phase.
  • Rotate the image by θ → the spectrum rotates by θ too. (Exact in the DFT only for multiples of 90°.)
  • Multiply by a wave: \(f[x,y]\,e^{2\pi i(u_0x/M+v_0y/N)} \Leftrightarrow F[u-u_0, v-v_0]\). This is the reason \((-1)^{x+y}\) centres the spectrum: \((-1)^{x+y} = e^{i\pi(x+y)}\), a shift by \((M/2, N/2)\).

The swap experiment (from the lecture)

Takeaway. Magnitude says how much of each frequency. Phase says where the edges are, and that is what our eyes use.

2D convolution theorem

\[ f * h \;\Leftrightarrow\; F\,H, \qquad f\,h \;\Leftrightarrow\; \tfrac{1}{MN}\,F * H \]

The DFT version is circular: the image wraps around at the edges. Zero-pad first, or the left edge leaks into the right edge.

Exam-style practice

DFT of \(f = [1, 0, 0, 0]\)? Of \(f = [0, 1, 0, 0]\)?
Answer

Impulse at 0: \(F = [1,1,1,1]\). Shifted by 1: multiply by \(e^{-2\pi iu/4} = (-i)^u\): \(F = [1, -i, -1, i]\). Same magnitudes, different phase.

A pattern with 30 cycles/cm is sampled at 40 samples/cm. What do you see?
Answer

Nyquist limit is 20 cycles/cm, so it aliases. The copy at 30 − 40 = −10 shows up: a 10 cycles/cm pattern.

Why does a sharp-edged object have a spectrum that spreads to high frequencies?
Answer

A sharp edge is like a step / box. Its transform is a sinc-like function that decays slowly (like \(1/\mu\)), so it has energy at high frequencies. Smooth objects have quickly decaying spectra.

Find the 2D DFT of the 2 × 2 image \(f = \begin{bmatrix}1&2\\3&4\end{bmatrix}\) (row index x, column index y).
Answer

With M = N = 2, \(e^{-2\pi i\,ux/2} = (-1)^{ux}\). So \(F[u,v] = \sum f[x,y](-1)^{ux+vy}\): plus or minus signs only.

  • \(F[0,0] = 1+2+3+4 = 10\) (sum)
  • \(F[1,0] = (1+2) - (3+4) = -4\) (top row − bottom row)
  • \(F[0,1] = (1+3) - (2+4) = -2\) (left column − right column)
  • \(F[1,1] = 1 - 2 - 3 + 4 = 0\) (diagonals)

\(F = \begin{bmatrix}10&-2\\-4&0\end{bmatrix}\). Check with the inverse: \(f[0,0] = \frac14(10 - 2 - 4 + 0) = 1\). ✓

A 256 × 256 image has vertical stripes that repeat every 8 pixels. Where are the bright spots in its centred spectrum?
Answer

The stripes change only along the horizontal direction, with 256 / 8 = 32 cycles across the image. So two spots at distance 32 from the centre on the horizontal axis, plus the DC spot in the centre.

You shift an image 10 pixels right. What happens to \(|F|\) and to the phase? You rotate it 90°?
Answer

Shift: \(|F|\) is unchanged; the phase changes by \(-2\pi u\cdot10/M\) (a linear ramp). Rotate 90°: the spectrum (magnitude and phase) rotates by 90° too.
