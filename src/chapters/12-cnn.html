One neuron, then layers

A neuron takes inputs \(x_1..x_n\), forms a weighted sum, and applies an activation \(h\):

\[ z = w^T x + b, \qquad a = h(z) \]

A layer does many neurons at once: \(a^l = h(W^l a^{l-1} + b^l)\). Stack layers: \(a^0 = x\), output \(y = a^L\).

Why activations matter. Without \(h\), the whole network collapses to one linear map: \(y = W^L \cdots W^1 x + b'\). Depth would add nothing.

Learning by gradient descent

Define a loss \(\mathcal L\) (how wrong the outputs are). Nudge every weight downhill:

\[ W^l \leftarrow W^l - \alpha\frac{\partial\mathcal L}{\partial W^l}, \qquad b^l \leftarrow b^l - \alpha\frac{\partial\mathcal L}{\partial b^l} \]

\(\alpha\) = learning rate. The gradients are computed efficiently by backpropagation (chain rule, from the output layer back to the input).

Convolutional layers

A fully connected layer on an image has a weight for every (input pixel, output pixel) pair. Far too many, and it ignores that images are shift-invariant. A conv layer uses one small kernel everywhere:

\[ a(i,j) = \sum_{c}\sum_{h,k} w(h,k,c)\;x(i+h, j+k, c) + b \]
  • Translation equivariant: shift the input, the feature map shifts the same way.
  • Parameter count: \(C_o \times C_i \times K \times K\) weights + \(C_o\) biases. Independent of image size.
  • (Like most deep learning code, this is really correlation, not convolution.)

Pooling, receptive field, architectures

  • Pooling (max or average over 2 × 2, stride 2) halves the resolution. Builds some shift invariance and grows the receptive field.
  • Receptive field: the input region that affects one output. Each 3 × 3 conv adds 2 pixels; each 2× pooling doubles the growth rate.
  • Early layers learn edge/colour detectors; deeper layers learn parts and objects.

Classification: image → one label (shrink to a vector). Segmentation: image → label per pixel (\(C_i\times H\times W \to C_o \times H\times W\)), e.g. U-Net, fully convolutional nets.

Exam-style practice

A conv layer maps a 3 × 256 × 256 image to 64 channels with 5 × 5 kernels. How many parameters? Compare with a fully connected layer producing 64 × 256 × 256 outputs.
Answer

Conv: \(64\times3\times5\times5 + 64 = 4864\). Fully connected: \((3\cdot256^2)\times(64\cdot256^2) \approx 8.2\times10^{11}\) weights. Conv shares weights across positions.

Show that a network of linear layers without activations is just one linear layer.
Answer

\(a^2 = W^2(W^1x + b^1) + b^2 = (W^2W^1)x + (W^2b^1 + b^2)\). By induction, any depth gives \(Wx + b\).

Three stacked 3 × 3 conv layers (stride 1, no pooling). What is the receptive field of one output pixel?
Answer

Each layer adds 2: 3 → 5 → 7. So 7 × 7. (Same as one 7 × 7 layer, but fewer weights: \(3\cdot9C^2 = 27C^2\) vs \(49C^2\).)

Cheat sheet · CNNs

  • \(z = w^Tx + b\), \(a = h(z)\); layer \(a^l = h(W^la^{l-1}+b^l)\)
  • No activation → whole net is linear
  • GD: \(W \leftarrow W - \alpha\,\partial\mathcal L/\partial W\); backprop = chain rule
  • Conv params: \(C_oC_iK^2 + C_o\)
  • Conv = shared weights → translation equivariant
  • Pool 2×2: halve size, grow receptive field
  • n stacked 3×3 → RF \(2n+1\)
