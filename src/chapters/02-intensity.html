Intensity transforms and histograms

Pre-minorDeck 03, 04

Point operations: one pixel at a time

An intensity transform maps each pixel value \(r\) to a new value \(s = T(r)\). It ignores neighbours. You can store \(T\) as a lookup table.

  • Negative: \(s = L - 1 - r\).
  • Brightness / contrast: \(s = c(r - k) + k\). Contrast up if \(c > 1\).
  • Log: \(s = \log(1 + r)\). Squashes a huge range. Used to display Fourier spectra.
  • Gamma: \(s = r^\gamma\) on [0, 1]. \(\gamma < 1\) brightens darks. \(\gamma > 1\) darkens.
Rule. \(T\) should be increasing. If not, ordering of intensities flips and you get odd inversions.

Contrast stretching and thresholding

Where the curve is steep, nearby input values get pushed apart: more contrast. Where it is flat, they get squashed together.

Thresholding is the extreme case: output is only 0 or 1.

The histogram

\(h(r)\) = how many pixels have value \(r\). Normalized: \(p(r) = h(r)/MN\). So \(p(r)\) is the chance a random pixel has value \(r\).

\[ m = \sum_r r\,p(r), \qquad \sigma^2 = \sum_r (r - m)^2\,p(r) \]

A narrow histogram means low contrast. Spreading it out improves contrast.

Histogram equalization

Goal: make the histogram as flat as possible. The trick: use the CDF as the transform.

\[ s_k = T(r_k) = (L-1)\sum_{j=0}^{k} p(r_j) \]

Why it works: if \(s = (L-1)\,\mathrm{CDF}(r)\), then the CDF of \(s\) is a straight line. A straight-line CDF means a flat histogram.

Why not perfectly flat? Levels are discrete. Several inputs merge into one output (4 → 6 and 3 → 6). You can never split one bin into two.

Local equalization and CLAHE

  • Local histogram equalization: for each pixel, equalize using only the histogram of a window around it. Brings out local detail.
  • Fast version: compute \(T\) per block, then interpolate between nearby blocks' \(T\)s.

Problem: the slope of \(T\) is \(T(r) - T(r-1) = (L-1)\,p(r)\). In a flat region the histogram has a tall spike, so the slope is huge. Noise gets amplified.

CLAHE = Contrast Limited AHE. Clip the histogram at a max height. Spread the clipped pixels evenly over all bins. This caps the slope, so it caps the contrast boost.

Histogram matching

Equalization makes the histogram flat. Matching makes it look like any target histogram \(p_z\) you choose.

  1. Equalize the input: \(s = T_r(r)\) (its CDF).
  2. Equalize the target too: \(s = T_z(z)\) (target CDF).
  3. Both give "flat" values \(s\), so connect them: \(z = T_z^{-1}(T_r(r))\).

In practice: for each input level \(r\), pick the \(z\) whose target CDF is closest to the input CDF at \(r\). (Store \(T_z\) as a table and search it.)

Worked example (4 levels)

level0123
input p_r0.40.30.20.1
input CDF0.40.70.91.0
target p_z0.10.20.30.4
target CDF0.10.30.61.0
r → z1233

Input CDF 0.4 is closest to target CDF 0.3, so 0 → 1. Then 0.7 → 0.6 (level 2), 0.9 → 1.0 (level 3), 1.0 → 1.0 (level 3). The new histogram is [0, 0.4, 0.3, 0.3]: close to the target, not exact (digital levels can't be split).

Exam-style practice

A 2-bit image (L = 4) has 16 pixels with counts \(h = [8, 4, 4, 0]\). Find the equalization map.
Answer

\(p = [.5, .25, .25, 0]\). CDF \(= [.5, .75, 1, 1]\). Multiply by 3: \([1.5, 2.25, 3, 3]\). Round: \(0\to2\) (1.5 rounds to 2), \(1\to2\), \(2\to3\), \(3\to3\).

Note 0 and 1 merge. Histogram is not flat, which is expected.

Is histogram equalization idempotent (does applying it twice change anything)?
Answer

In the continuous case, yes: the output is already uniform, so its CDF is a straight line and \(T\) is the identity. In the discrete case it is (almost) idempotent too: the second pass maps each occupied level to itself or very close.

Cheat sheet · intensity

  • Matching \(z = T_z^{-1}(T_r(r))\): pick z with target CDF closest to input CDF
  • Negative: \(L-1-r\)
  • Contrast: \(c(r-k)+k\)
  • Gamma: \(r^\gamma\); \(\gamma<1\) brightens
  • Log: \(\log(1+r)\), for spectra
  • Mean \(\sum r p(r)\), var \(\sum (r-m)^2 p(r)\)
  • Hist. eq.: \(s_k = (L-1)\sum_{j\le k} p_j\), round
  • Slope of T = \((L-1)p(r)\) → CLAHE clips p
  • Discrete eq.: never perfectly flat (bins merge)
