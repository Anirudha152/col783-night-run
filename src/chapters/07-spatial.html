Spatial filters: smoothing and sharpening

Pre-minorDeck 04, 05 · Minor Q2

Correlation and convolution

A linear filter replaces each pixel by a weighted sum of its neighbours. The weights form the kernel \(w\).

\[ \text{correlation: } (w\star f)(x) = \sum_s w(s)\,f(x+s) \qquad \text{convolution: } (w*f)(x) = \sum_s w(s)\,f(x-s) \]

Convolution = correlation with a flipped kernel. For symmetric kernels they are the same.

Impulse test

f0 0 0 1 0 0 0 0
w1 2 4 2 8
correlation0 8 2 4 2 1 0 0
convolution0 1 2 4 2 8 0 0

Convolving with an impulse gives back a copy of the kernel. Correlation gives a flipped copy.

  • Convolution is commutative, associative, distributive. Correlation is not commutative or associative.
  • Big kernel \(m\times n\) on an \(M\times N\) image: \(O(MNmn)\). If separable (\(w = u v^T\)), do rows then columns: \(O(MN(m+n))\).

Smoothing: box, Gaussian, median

  • Box (mean): all weights \(1/mn\). Simple but makes blocky artefacts.
  • Gaussian: weights \(\propto e^{-(s^2+t^2)/2\sigma^2}\). Smooth, separable. Use kernel width ≈ \(6\sigma\).
  • Median: sort the window, take the middle. Nonlinear. Best for salt-and-pepper noise. Keeps edges sharp but rounds corners.
  • Min / max: also order-statistic filters. (They are gray erosion / dilation.)

Mean of \(mn\) noisy values cuts noise variance by \(mn\) (if the region is truly flat).

Bilateral filter: smooth but keep edges

\[ g(p) = \frac{1}{W(p)}\sum_q G_s(\|p-q\|)\;G_r(|f(p)-f(q)|)\;f(q) \]
  • \(G_s\): spatial Gaussian. Near pixels count more.
  • \(G_r\): range Gaussian. Pixels with similar intensity count more.
  • \(W(p)\) = sum of all weights, so they add to 1.

Across an edge the intensity jumps, so \(G_r \approx 0\) and those pixels are ignored. Result: flat areas get smoothed, edges stay sharp.

  • Not linear: weights depend on the image itself.
  • Cross (joint) bilateral: take \(G_r\) from a flash photo (clean edges) but average the no-flash photo.
  • HDR tone mapping: split \(f = \) base (bilateral) + detail, compress only the base.

Derivatives and sharpening

\[ f'(x) \approx f(x+1)-f(x), \qquad f''(x) \approx f(x+1) - 2f(x) + f(x-1) \]
Laplacian ∇²
sharpen: f − ∇²f
Sobel ∂/∂x
  • Laplacian sharpening: \(g = f - c\,\nabla^2 f\) (with the −4 centre kernel). Adds back edges.
  • Unsharp masking: \(g = f + k\,(f - f_{\text{blur}})\). \(k = 1\) unsharp, \(k > 1\) high-boost.
  • Gradient magnitude \(\sqrt{f_x^2 + f_y^2}\) for edges (more in the edge chapter).

Derivative kernels sum to 0 (flat input → 0 output). Smoothing kernels sum to 1 (flat input unchanged).

Template matching

Find where a small template \(w\) appears in image \(f\).

  • Plain correlation \(\sum w f\): fooled by bright regions.
  • SSD \(\sum (w - f)^2\): fooled by lighting changes.
  • Normalized cross-correlation (subtract means, divide by norms). Invariant to brightness offset and contrast scale. Peak = match.
\[ g(x) = \frac{\sum_s (w(s)-\bar w)(f(x+s)-\bar f_x)}{\sqrt{\sum_s (w(s)-\bar w)^2\,\sum_s (f(x+s)-\bar f_x)^2}} \]

Exam-style practice

Minor Q2 styleA portrait app should smooth skin blemishes but keep the eyes, lips and hair edges sharp, changing only intensity and not chromaticity. Then: what if the hair is blonde, with the same intensity as skin?
Answer

Convert to a space that separates intensity from chromaticity (YCbCr or HSI). Apply a bilateral filter to the intensity channel only: spatial Gaussian ≈ blemish size, range σ small enough that edges (eyes, lips) are not crossed.

Blonde hair: intensity does not separate hair from skin, so the range term would blur them together. Fix: compute the range weight from colour difference (e.g. distance in CbCr / hue, or full colour), but still only average the intensity channel. That is a cross/joint bilateral filter guided by chromaticity.

Minor Q2(c) styleDim photos have the same background as a well-lit reference. Fix their intensities automatically. What if backgrounds have different colours?
Answer

Histogram matching (specification) of the intensity channel to the reference: \(s = G^{-1}(T(r))\) where \(T, G\) are the CDFs. Since content is similar, the histograms should match.

If backgrounds differ, the histograms differ for reasons other than lighting. Then estimate the lighting from a region whose true appearance is known (e.g. the subject, or a gray patch), or fit a simple gain/offset \(s = ar + b\) using only matched regions.

Is the median filter linear? Prove it.
Answer

No. Take windows \(f = [0,0,1]\) and \(g = [0,1,0]\). median(f) = 0, median(g) = 0, but median(f+g) = median([0,1,1]) = 1 ≠ 0.

Cheat sheet · spatial filters

  • Corr \(\sum w(s)f(x+s)\); conv \(\sum w(s)f(x-s)\)
  • Conv with impulse = kernel; corr = flipped kernel
  • Separable: \(O(MN(m+n))\) instead of \(O(MNmn)\)
  • Gaussian width ≈ 6σ; smoothing kernels sum to 1
  • Median: salt & pepper; nonlinear
  • Bilateral \(\frac1W\sum G_s G_r(f_p - f_q) f_q\)
  • Laplacian [0 1 0; 1 −4 1; 0 1 0]; sharpen \(f - \nabla^2 f\)
  • Unsharp \(f + k(f - f_{\text{blur}})\)
  • Sobel x [−1 0 1; −2 0 2; −1 0 1]
  • NCC: subtract means, divide norms
  • Hist. matching \(s = G^{-1}(T(r))\)
