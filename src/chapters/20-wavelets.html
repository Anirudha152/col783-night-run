Why wavelets: sparsity

A signal is sparse in a basis if only a few coefficients are far from zero.

Take a step \(f = [0 \cdots 0\ 1 \cdots 1]\):

BasisNonzero coefficients
Standard (pixels)O(N)
FourierO(N)
HaarO(log N): only wavelets that straddle the jump, one per scale
  • Compression: keep only the biggest coefficients (top 10%, even top 1% still looks fine).
  • Denoising: a clean image is sparse but noise is spread over all coefficients. Zero the small ones.

Scaling functions and wavelets

\[ \phi_{jk}(x) = 2^{j/2}\,\phi(2^jx - k), \qquad \psi_{jk}(x) = 2^{j/2}\,\psi(2^jx - k) \]
  • \(j\) = scale (bigger \(j\) = narrower), \(k\) = position. \(2^{j/2}\) keeps the norm 1.
  • \(\phi_{jk}\) gives approximation coefficients \(a_{jk}\); \(\psi_{jk}\) gives detail coefficients \(d_{jk}\).
  • All \(\phi\)'s at one scale are orthogonal; all \(\psi\)'s too; and \(\psi_{jk} \perp \phi_{jk'}\).
\[ f(x) = \sum_k a_{jk}\phi_{jk}(x) + \sum_{j'\ge j}\sum_k d_{j'k}\,\psi_{j'k}(x) \]

Nested spaces

\(V_j\) = functions you can draw with scale-\(j\) boxes (piecewise constant on pieces of width \(2^{-j}\)).

  • \(V_j \subset V_{j+1}\): anything at a coarse scale can be drawn at a finer one.
  • \(W_j\) = the details you need to go from \(V_j\) to \(V_{j+1}\) = span of \(\psi_{jk}\).
\[ V_{j+1} = V_j \oplus W_j \]

To design a new wavelet: pick \(\phi, \psi\) so that this holds (ideally keeping orthogonality). A tent function \(\phi\) fails: shifted tents overlap (not orthogonal) and there is no obvious \(\psi\).

Refinement relation

\(\phi\) lives in \(V_0 \subset V_1\), so it is a combination of narrower \(\phi\)'s:

\[ \phi = \sum_k h_\phi[k]\,\phi_{1k}, \qquad \psi = \sum_k h_\psi[k]\,\phi_{1k} \]

Haar: \(h_\phi = [\tfrac{1}{\sqrt2}, \tfrac{1}{\sqrt2}]\), \(h_\psi = [\tfrac{1}{\sqrt2}, -\tfrac{1}{\sqrt2}]\). The filters \(h_\phi, h_\psi\) fully determine \(\phi, \psi\). Daubechies wavelets (db4 etc.) are carefully chosen longer filters.

The fast wavelet transform

Start with \(a_0 = f\). Then repeatedly:

\[ a_j = \downarrow_2(h_\phi \star a_{j+1}), \qquad d_j = \downarrow_2(h_\psi \star a_{j+1}) \]

That is: correlate with each filter, keep every second sample. Recurse on \(a\) only.

Inverse: upsample and convolve with the (not reversed) filters, then add:

\[ a_{j+1} = h_\phi * \uparrow_2(a_j) + h_\psi * \uparrow_2(d_j) \]

Wavelets in 2D

Products of 1D functions give one scaling function and three wavelets:

\[ \phi(x)\phi(y),\quad \psi^H = \psi(x)\phi(y),\quad \psi^V = \phi(x)\psi(y),\quad \psi^D = \psi(x)\psi(y) \]

The three detail bands respond to edges of different orientations; the approximation is a small blurred copy.

Denoising: hard vs soft thresholding

  1. Wavelet transform of the noisy image.
  2. Threshold the detail coefficients (not the coarse approximation).
  3. Inverse transform.

Hard keeps big coefficients exact but can leave blips. Soft gives smoother results, slightly shrinks edges.

Why normalize? Use the orthonormal Haar for thresholding. Then coefficient error = pixel error, so "drop the smallest coefficients" really means "lose the least". With plain averages/differences, a coarse-scale difference affects many pixels but has a small value, so it gets dropped wrongly.

Exam-style practice

For \(f = [0,0,0,0,0,1,1,1]\), compute the unnormalized Haar transform (means and differences). How many nonzero detail coefficients?
Answer

Level 1: means [0, 0, 0.5, 1], diffs [0, 0, −1, 0]. Level 2: means [0, 0.75], diffs [0, −0.5]. Level 3: mean [0.375], diff [−0.75].

Transform: [0.375, −0.75, 0, −0.5, 0, 0, −1, 0]. Only 3 nonzero details: one per scale, at the jump. O(log N).

Apply soft thresholding with τ = 1 to coefficients \([5, -0.4, 2, -3, 0.8]\). And hard?
Answer

Soft: [4, 0, 1, −2, 0]. Hard: [5, 0, 2, −3, 0].

Why is the fast wavelet transform O(N) but the FFT O(N log N)?
Answer

Each level costs O(size) and only the approximation (half the size) is processed again: \(N + N/2 + N/4 + \dots = 2N\). The FFT recurses on both halves: \(T(N) = 2T(N/2) + O(N)\).
