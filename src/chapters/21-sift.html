Scale space

Harris corners are not scale invariant: a zoomed-in corner looks like an edge to a fixed-size window. Fix: look at the image at every blur level.

\[ L(x, y, \sigma) = G_\sigma * f \]

Why Gaussian? It never creates new extrema when blurring more; coarser levels are fully determined by finer ones (causality); it is rotation-symmetric and shift-invariant.

  • Gaussian pyramid ≈ scale space at σ, 2σ, 4σ, …
  • Finer steps: σ, kσ, k²σ, … with \(k = 2^{1/s}\). An octave (doubling of σ) holds \(s\) steps (\(s + 1\) images). In practice \(s \approx 4\).

Blobs = extrema of the DoG

\[ D(x,y,\sigma) = L(x,y,k\sigma) - L(x,y,\sigma) \approx (k-1)\,\sigma^2\,\nabla^2 G * f \]
  • DoG (difference of Gaussians) is a cheap approximation of the scale-normalized LoG, \(\sigma^2\nabla^2G\).
  • Bright and dark blobs = local maxima/minima of \(D\) in x, y and σ. Check all 26 neighbours: 8 at the same scale, 9 above, 9 below.
  • The σ where a blob's response peaks is its characteristic scale. It grows with the blob, so detection is scale-covariant.
Why multiply by σ²? The plain LoG response gets weaker as σ grows (more blur, smaller derivatives), so bigger scales would always lose. \(\sigma^2\nabla^2 G\) (and DoG) give the same peak value for a blob and its scaled copy: scale invariant.

Harris–Laplace: find Harris corners, then pick each one's scale by maximizing \(|\sigma^2\,\text{LoG}|\), re-locate, repeat.

Sub-pixel accuracy with Taylor series

The true peak lies between samples. Fit a parabola through the sample and its neighbours:

\[ f(x+h) \approx f(x) + f'(x)h + \tfrac12 f''(x)h^2 \;\Rightarrow\; h^* = -\frac{f'(x)}{f''(x)},\quad f(x+h^*) \approx f(x) + \tfrac12 f'(x)h^* \]

Use \(f' = \frac{f(x+1) - f(x-1)}{2}\) and \(f'' = f(x+1) - 2f(x) + f(x-1)\). (This equals quadratic interpolation.)

In several dimensions (x, y, σ): \(v^* = -H^{-1}\nabla f\), value \(f + \tfrac12\nabla f^Tv^*\), with \(H\) the Hessian.

Example

Samples 2, 5, 4 at x = −1, 0, 1. \(f' = 1\), \(f'' = -4\). \(h^* = 0.25\), peak ≈ \(5 + 0.5\cdot1\cdot0.25 = 5.125\).

SIFT keypoints: filter, orient

  1. Find DoG extrema, refine with Taylor.
  2. Drop low contrast: \(|D| < 0.03\) (for intensities in [0, 1]).
  3. Drop edges: DoG responds along edges too. Use the 2 × 2 Hessian \(H = \begin{bmatrix}D_{xx}&D_{xy}\\D_{xy}&D_{yy}\end{bmatrix}\); keep only if \(\lambda_{\min} > \lambda_{\max}/r\): \[ \frac{\operatorname{tr}(H)^2}{\det H} < \frac{(r+1)^2}{r} \quad (r = 10 \Rightarrow 12.1) \]
  4. Orientation: histogram of gradient directions around the point (on \(L(\cdot,\sigma)\), not on \(f\)), weighted by gradient magnitude and a Gaussian. Peak = orientation. Any other peak above 80% of the top makes an extra keypoint.
Soft binning. Don't put a value only in the nearest bin (small shifts flip bins). Split it between the two nearest bins with linear weights (e.g. 0.55 / 0.45). Same trick helps Hough and local histograms.

SIFT descriptor and matching

Matching: nearest neighbour in 128-D. Reject ambiguous matches with the ratio test: keep only if \(d_{\text{nearest}} < 0.8\,d_{\text{2nd nearest}}\).

Exam-style practice

HomeworkShow \(G_{k\sigma} - G_\sigma \approx (k-1)\sigma^2\nabla^2G_\sigma\) for \(k\) near 1.
Answer

The Gaussian satisfies the heat equation \(\frac{\partial G}{\partial\sigma} = \sigma\nabla^2 G\). So \(G_{k\sigma} - G_\sigma \approx \frac{\partial G}{\partial\sigma}(k\sigma - \sigma) = (k-1)\sigma\cdot\sigma\nabla^2G = (k-1)\sigma^2\nabla^2 G\).

At a DoG extremum, \(D_{xx} = 20\), \(D_{yy} = 1\), \(D_{xy} = 0\). Keep or reject (r = 10)? What if \(D_{xx} = 4\)?
Answer

Threshold \((r+1)^2/r = 12.1\). First: tr = 21, det = 20, tr²/det = 22.05 > 12.1 → reject (edge; eigenvalue ratio 20). Second: tr = 5, det = 4, 25/4 = 6.25 < 12.1 → keep.

Samples 3, 6, 6 at x = −1, 0, 1. Where is the refined peak and its value?
Answer

\(f' = (6 - 3)/2 = 1.5\), \(f'' = 6 - 12 + 3 = -3\). \(h^* = 0.5\). Value \(= 6 + 0.5\cdot1.5\cdot0.5 = 6.375\).

Why compute the SIFT orientation and descriptor on \(L(x,y,\sigma)\) and not on \(f\)?
Answer

To keep scale invariance: at the detected σ, the blurred image looks the same no matter how much the original was zoomed. Gradients of \(f\) itself would change with image scale.

Cheat sheet · SIFT

  • \(L = G_\sigma*f\); Gaussian: no new extrema, causal
  • Octave: \(k = 2^{1/s}\), s ≈ 4
  • DoG \(L(k\sigma)-L(\sigma)\approx(k-1)\sigma^2\nabla^2G*f\)
  • Extrema in (x, y, σ): 26 neighbours
  • σ²-normalized LoG ⇒ scale invariant
  • Refine \(h^* = -f'/f''\), value \(f+\frac12f'h^*\); nD \(-H^{-1}\nabla f\)
  • Reject \(|D|<0.03\); edges: \(\text{tr}^2/\det \ge (r+1)^2/r\) (12.1)
  • Orientation: grad histogram, peaks ≥ 80%; soft binning
  • Descriptor 4×4×8 = 128; normalize, clip 0.2, renormalize
  • Match: ratio test \(d_1 < 0.8\,d_2\)
