What derivatives do at an edge

An edge is where intensity changes fast. Real edges are blurred steps: ramps. (A smoothing filter applied to a step gives a ramp.)

  • Size of \(f'\) tells you an edge is there.
  • The zero crossing of \(f''\) tells you exactly where. Its sign tells you which side is dark.
  • Roof edge (thin line) = two ramps back to back.
Noise. Derivatives amplify noise badly (second derivative even more). Always smooth first. Steps: (1) smooth, (2) find candidate edge points, (3) localize/thin them.

Gradient and Sobel

\[ \nabla f = \begin{bmatrix} \partial f/\partial x \\ \partial f/\partial y\end{bmatrix}, \quad \|\nabla f\| = \sqrt{f_x^2 + f_y^2}, \quad \alpha = \tan^{-1}(f_y / f_x) \]
  • The gradient points across the edge (perpendicular to the edge direction).
  • Derivative in direction \(d\): \(\nabla f \cdot d\).

Sobel = central difference in one direction × small smoothing [1 2 1] in the other. Simple detector: smooth, Sobel, threshold \(\|\nabla f\|\). Edges come out thick.

Marr-Hildreth: zero crossings of LoG

Convolve with the Laplacian of Gaussian, then mark zero crossings.

\[ g = \nabla^2 G * f = \nabla^2 (G * f), \qquad \nabla^2 G(x,y) = \frac{x^2+y^2-2\sigma^2}{\sigma^4}\,e^{-\frac{x^2+y^2}{2\sigma^2}} \]
  • \(\sigma\) sets the scale: big σ finds only big, strong edges.
  • Fast: Gaussian (separable) then a 3 × 3 Laplacian. Keep Gaussian width ≥ 6σ.
  • Zero crossing at a pixel: sign of \(g\) differs between opposite neighbours (left/right, up/down, or diagonals).
  • Keep only strong edges: also need \(|g(x+1) - g(x-1)| >\) threshold.
  • Why \(\nabla^2(G*f) = (\nabla^2 G)*f\): derivatives commute with convolution, \(\frac{d}{dx}(g*f) = \frac{dg}{dx}*f\).

Quiz 4 Q2, solved: dark line on white

One column of the image: white, a narrow dark dip, white. Smooth with Gaussian h to get g. Sketch g, dg/dx, ∇²g. Mark Marr-Hildreth edges.

  • \(g\) is an upside-down bell.
  • \(dg/dx\): negative on the left wall of the dip, zero at the bottom, positive on the right wall.
  • \(\nabla^2 g\): the dip bottom curves upward, so \(\nabla^2 g > 0\) in the middle and \(< 0\) on the shoulders.
  • Two zero crossings, one on each side of the line. Those are the edges (the line's two borders), where \(|dg/dx|\) peaks.

Does the width of the line matter? Yes.

\(g\) = (box of width \(w\)) * (Gaussian of width \(\sigma\)). What you get depends on which is wider.

  • Narrow line (\(w\) small next to \(\sigma\)), the case in the quiz: the box acts like a spike, so \(g\) ≈ a Gaussian dip with a round bottom (the plots above). The blur also makes the dip shallower. The zero crossings land where the dip bends, about \(\pm\sqrt{\sigma^2 + w^2/12}\): a bit outside the true borders.
  • Wide line (\(w\) big next to \(\sigma\)): the two borders are blurred separately and don't touch. \(g\) has a flat bottom. \(dg/dx\) is two separate bumps with 0 between them. \(\nabla^2 g\) is − + (zero) + − and crosses zero exactly at the two true borders.
Exam tip. If the question says "narrow" or "thin" line, draw the round-bottom version. Either way, Marr-Hildreth gives two edges, one per border, never one in the middle.

Canny edge detector

Idea: an edge is where the brightness changes fastest, i.e. where the gradient magnitude peaks as you walk across the edge. (Marr-Hildreth instead looks where the 2nd derivative crosses zero.)

  1. Smooth with a Gaussian: \(g = G_\sigma * f\). Removes noise; σ picks the scale (bigger σ = only big, strong edges).
  2. Gradient of \(g\) (e.g. Sobel): \(M = \sqrt{g_x^2 + g_y^2}\) (strength) and \(\theta = \operatorname{atan2}(g_y, g_x)\) (direction). θ points across the edge, from dark to bright.
  3. Non-maximum suppression (NMS): after blurring, \(M\) is a thick ridge several pixels wide. Keep only the top of the ridge. Round θ to one of 4 directions (0°, 45°, 90°, 135°). Compare \(M\) with its 2 neighbours along θ. If either is bigger, set \(M = 0\). Edges become 1 pixel thin.
  4. Hysteresis thresholding with two thresholds \(T_{\text{low}} < T_{\text{high}}\) (ratio about 1 : 2 or 1 : 3):
    • \(M \ge T_{\text{high}}\): strong, surely an edge.
    • \(T_{\text{low}} \le M < T_{\text{high}}\): weak, kept only if connected (8-neighbours, through other weak pixels) to a strong pixel.
    • \(M < T_{\text{low}}\): dropped.
    This is morphological reconstruction: marker = strong pixels, mask = strong + weak.

Link. In 1D they find the same point: where \(g'\) peaks, \(g''\) is zero. In 2D they differ, because the Laplacian adds curvature along the edge too, not just across it. Canny is near-optimal for a step edge in Gaussian noise (1D: maxima of \(G' * f\)), so it gives thinner, cleaner, better-connected edges.

Hough transform for lines

What Hough is, for any shape. A voting method. (1) Write the shape as an equation with a few unknown numbers, its parameters. (2) Make a grid of counters, one cell per possible parameter value (the accumulator). (3) Every edge pixel votes for every shape that could pass through it. (4) Cells with many votes = shapes that really are in the image. Noise and gaps don't matter much: random pixels spread their votes thinly.

Edge pixels are scattered. Which straight lines pass through many of them? A line needs 2 numbers. \(y = mx + c\) fails for vertical lines (\(m = \infty\)), so use the normal form: ρ = distance from the origin, θ = angle of the line's normal.

\[ x\cos\theta + y\sin\theta = \rho \] 
A[ρ, θ] = 0
for each edge pixel (x, y):
    for each θ_j:
        ρ = x cos θ_j + y sin θ_j
        A[round(ρ), j] += 1
lines = peaks of A
  • Point in image ↔ curve in parameter space. Line in image ↔ point in parameter space.
  • Normal form avoids infinite slopes (vertical lines are fine).
  • Speed-ups: use the gradient direction, so each pixel votes only for θ near its gradient angle; weight votes by \(\|\nabla f\|\). Progressive probabilistic Hough: add pixels randomly, report a line once its bin is significant, then remove its pixels.

Hough for circles, and Quiz 4 Q4

General circle \((x-a)^2 + (y-b)^2 = r^2\) has 3 parameters → 3D accumulator. Too slow. Two tricks:

  • Fix r: for each edge pixel, loop over an angle φ around it: \(a = x - r\cos\varphi,\ b = y - r\sin\varphi\). (Each pixel votes for a circle of possible centres.) 2D accumulator.
  • Use the gradient: the centre lies along the gradient line, so loop only over r: \(a = x \mp r\cos\alpha\), \(b = y \mp r\sin\alpha\).
No ρ, θ here. ρ and θ are the parameters of a line. For another shape, use that shape's parameters: a circle uses \((a, b, r)\); a circle touching the x-axis uses \((c, d)\). The method is the same: loop over some parameters, solve the shape's equation for the rest, add a vote.

Quiz 4 Q4: circles tangent to the x-axis

Centre \((c, d)\), radius \(d\). Condition \((x-c)^2 + (y-d)^2 = d^2\). Expand:

\[ c^2 - 2xc + x^2 + y^2 - 2yd = 0 \;\Rightarrow\; d = \frac{(x-c)^2 + y^2}{2y} \] 
A[c, d] = 0                     // only 2 parameters
for each edge pixel (x, y) with y ≠ 0:
    for each c in range:
        d = ((x − c)² + y²) / (2y)
        A[c, round(d)] += 1
circles = peaks of A

Exam-style practice

Give an efficient Hough algorithm for circles whose centres lie on the x-axis.
Answer

Centre \((c, 0)\), radius \(r\): \((x-c)^2 + y^2 = r^2\) → \(r = \sqrt{(x-c)^2 + y^2}\).

For each edge pixel, for each \(c\): compute \(r\), increment \(A[c, \text{round}(r)]\). Peaks = circles. 2D accumulator.

Detect only lines through the origin. What accumulator do you need?
Answer

\(\rho = 0\), so \(x\cos\theta + y\sin\theta = 0\) → \(\theta = \operatorname{atan2}(-x, y)\) (mod π). Each pixel votes once in a 1D accumulator over θ.

Sketch g, g′ and ∇²g for a single upward step edge smoothed by a Gaussian. Where is the Marr-Hildreth edge?
Answer

g is a ramp (S-curve). g′ is a bump (positive peak) at the edge. g″ is positive before the edge, negative after (or vice versa), with one zero crossing exactly at the peak of g′. That zero crossing is the edge.

Why do we use the normal form \(\rho = x\cos\theta + y\sin\theta\) and not \(y = mx + c\)?
Answer

\(m\) is unbounded (infinite for vertical lines), so the accumulator cannot cover it. \(\theta \in [0, \pi)\) and \(|\rho| \le\) image diagonal are both bounded.
