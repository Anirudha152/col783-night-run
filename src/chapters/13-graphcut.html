Segmentation by graph cuts and watersheds

Post-minorDeck 23

Images as graphs

Make each pixel a vertex. Connect neighbours (or all nearby pairs) with edges weighted by similarity:

\[ w(i,j) = \frac{1}{\|p_i - p_j\|}\exp\!\Big(-\frac{(l_i - l_j)^2}{2\sigma^2}\Big) \]

A segmentation splits vertices into sets \(A, B\). Its cut cost is the total weight of edges between them:

\[ \text{cut}(A,B) = \sum_{u\in A,\,v\in B} w(u,v) \]

Small cut = we only separated pixels that were dissimilar. Good.

Mean shift (finding modes of a density estimate) is in the deck but marked not on the exam.

Graph cut with user marks (Boykov–Jolly)

\[ E(a) = \lambda\sum_i R_i(a_i) + \sum_{i,j \text{ nbrs}} B_{ij}\,[a_i \neq a_j] \]
  • \(a_i\) = label of pixel \(i\) (object / background).
  • Region cost \(R_i\): how badly pixel \(i\) fits that label. From histograms of user-marked pixels: \(R_i(\text{obj}) = -\ln P(l_i \mid \mathcal O)\), \(R_i(\text{bkg}) = -\ln P(l_i\mid\mathcal B)\).
  • Boundary cost \(B_{ij}\): penalty for cutting between similar neighbours (large when \(l_i \approx l_j\)).
  • Add terminals \(s\) (object) and \(t\) (background). t-links carry \(\lambda R_i\), n-links carry \(B_{ij}\).
  • Any s–t cut = a labelling, and its cost = \(E(a)\).
  • Min cut = max flow: solved exactly and fast for 2 labels.

GrabCut and normalized cuts

GrabCut: just draw a box

  1. Start: outside the box = background, inside = maybe object.
  2. Fit colour models (Gaussian mixtures) for each class.
  3. Graph cut with those region costs.
  4. Repeat 2–3.

Normalized cut (no user input)

Plain min cut likes to chop off tiny groups (few edges to cut). Normalize by group size:

\[ \text{ncut}(A,B) = \frac{W(A,B)}{W(A,V)} + \frac{W(A,B)}{W(B,V)} \]
  • Exact minimization is NP-hard.
  • Relax labels \(x_i \in \{-1, 1\}\) to real \(y_i\) → generalized eigenproblem \((D - W)y = \lambda D y\), with \(D_{ii} = \sum_j w(i,j)\).
  • Smallest eigenvalue 0 gives \(y = \mathbf 1\) (useless). Take the eigenvector of the second smallest eigenvalue, then threshold it.
  • Often run on a region adjacency graph of superpixels to keep it small.

Watershed segmentation

See the image as terrain: intensity = height. Rain flows downhill to a local minimum.

  • Sublevel sets \(T(l) = \{f \le l\}\) grow as \(l\) rises. Track their connected components.
  • A new component appears → a new basin. Two components touch → build a dam there.
  • Run it on the gradient magnitude: basins = flat regions, dams = edges.
Over-segmentation. Noise makes many tiny minima → too many regions. Fix with markers: only allow basins to start at chosen markers (internal markers e.g. h-minima of the object, external markers e.g. watersheds of smoothed intensity).

Touching round objects: watershed on the negated distance transform splits them at their necks.

Exam-style practice

HomeworkRun Boykov–Jolly on a superpixel adjacency graph. How should you set region weights and edge weights so every superpixel-wise labelling has the same cost as on the pixel graph?
Answer

Region cost of superpixel \(S\) = sum of its pixels' region costs: \(R_S(a) = \sum_{i\in S} R_i(a)\). Edge weight between superpixels \(S, T\) = sum of \(B_{ij}\) over all neighbouring pixel pairs with \(i\in S, j \in T\). Edges inside a superpixel are never cut, so they can be dropped.

HomeworkMarker-based watershed: what happens when two flooding components meet if both, one, or neither contain a marker?
Answer

Both have (different) markers → build a dam (they stay separate). One has a marker → merge; the unmarked one joins the marked basin. Neither has a marker → merge them (they will join whichever marked basin they reach later).

Why does plain min cut give bad segmentations without terminals or normalization?
Answer

The cut cost grows with the number of edges cut. Isolating a single pixel cuts only a few edges, so the minimum cut tends to slice off tiny groups. Normalized cut divides by each side's total connection, so tiny sets get a big penalty.

Cheat sheet · graph cuts, watersheds

  • \(w(i,j) = \frac{1}{\|p_i-p_j\|}e^{-(l_i-l_j)^2/2\sigma^2}\)
  • \(\text{cut}(A,B) = \sum_{A\times B} w\)
  • \(E = \lambda\sum R_i(a_i) + \sum B_{ij}[a_i\ne a_j]\)
  • \(R_i(\text{obj}) = -\ln P(l_i\mid\mathcal O)\)
  • s–t min cut = max flow (exact, 2 labels)
  • GrabCut: box → GMMs ↔ graph cut, iterate
  • ncut \(= \frac{W(A,B)}{W(A,V)}+\frac{W(A,B)}{W(B,V)}\)
  • \((D-W)y=\lambda Dy\), 2nd smallest eigvec, threshold
  • Watershed: flood from minima, dams on merge; use \(\|\nabla f\|\)
  • Markers fix over-segmentation; −DT splits blobs
