Colour image processing

Pre-minorDeck 06

What colour is

  • Light has a spectrum: power at each wavelength.
  • The eye has 3 cone types (L, M, S). The brain only gets 3 numbers.
  • Different spectra with the same 3 cone responses look identical: metamers.
  • So 3 primaries can reproduce (almost) any colour sensation. The amounts are tristimulus values X, Y, Z.
\[ x = \frac{X}{X+Y+Z},\quad y = \frac{Y}{X+Y+Z},\quad z = 1 - x - y \]

\(x, y\) = chromaticity (colour without brightness). Plotting them gives the horseshoe chromaticity diagram. Any colour made from 3 primaries lies inside their triangle: the gamut.

  • Luminance: physical intensity seen by the eye. Brightness: how bright it feels.
  • Chromaticity = hue (which colour) + saturation (how pure).

RGB and CMY(K)

A colour model is a coordinate system (RGB). A colour space pins it to real colours (sRGB: exact primaries, white point, gamma).

HSI: separate intensity from colour

  • \(I = (R + G + B)/3\).
  • \(S = 1 - \dfrac{3\min(R,G,B)}{R+G+B}\): distance from the gray axis. Gray → 0.
  • \(H\) = angle around the gray axis (0° red, 120° green, 240° blue).

H and S depend only on the proportions R/(R+G+B) etc., not on brightness.

Trap. Hue jumps from 360° to 0° at red. Averaging or blurring hue directly is wrong near red. And hue is undefined when S = 0.

YCbCr

\[ Y' = 0.299R' + 0.587G' + 0.114B',\quad C_B = 128 + \frac{B'-Y'}{2(1-0.114)},\quad C_R = 128 + \frac{R'-Y'}{2(1-0.299)} \]

Linear and cheap. Used in JPEG and video. Y' = brightness, Cb/Cr = colour.

Processing colour images

  • Per-channel on R, G, B: fine for linear filters (blur on each channel = blur on the vector).
  • Histogram equalization per RGB channel changes the colour balance (hues shift). Better: equalize only I (or Y), keep H, S.
  • Sharpen / smooth only intensity when you want colours unchanged.
  • Colour segmentation: threshold the distance to a target colour in RGB, or threshold hue and saturation.
  • Colour edges: gradients of each channel can cancel; use a combined vector gradient.

Pseudocolour (false colour)

People can tell apart thousands of colours, but only a few dozen grays. So we paint gray or multi-band images in colour just to see them better.

  • Intensity slicing: give each intensity range its own colour (e.g. highlight saturated pixels in red).
  • Gray → colour map: three functions \(R(f), G(f), B(f)\) (like a heat map).
  • Multispectral: put a different band in each channel, e.g. (infrared, green, blue) shown as (R, G, B). Plants glow red because they reflect infrared strongly.
Accessibility. Colour-blind viewers may not see red vs green. Do not rely on colour alone to show information.

Exam-style practice

Convert RGB = (0.2, 0.4, 0.6) to CMYK.
Answer

CMY = (0.8, 0.6, 0.4). K = 0.4. C = (0.8−0.4)/0.6 = 0.667, M = 0.2/0.6 = 0.333, Y = 0. So CMYK ≈ (0.67, 0.33, 0, 0.4).

You equalize the histograms of R, G, B separately on a photo with a blue sky. What can go wrong? What should you do instead?
Answer

Each channel gets a different transform, so the ratios R:G:B change and hues shift (sky may turn odd colours). Instead, convert to HSI (or YCbCr), equalize I (or Y) only, and convert back.

Compute I and S for RGB = (0.6, 0.3, 0.3).
Answer

I = 1.2/3 = 0.4. S = 1 − 3(0.3)/1.2 = 1 − 0.75 = 0.25. Hue is red (0°) since G = B < R.

Cheat sheet · colour

  • Chromaticity \(x = X/(X+Y+Z)\), \(x+y+z=1\)
  • Metamers: same LMS, different spectra
  • CMY \(=1-\)RGB; \(K=\min\), \(C\leftarrow(C-K)/(1-K)\)
  • I \(=(R+G+B)/3\); S \(=1-3\min/(R+G+B)\)
  • H: angle; wraps at red; undefined if S = 0
  • Y' \(=.299R+.587G+.114B\)
  • Equalize I/Y only, not R, G, B separately
