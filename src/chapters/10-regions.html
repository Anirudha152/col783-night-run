Region segmentation: thresholds and clusters

Post-minorDeck 22

Segmentation = labelling every pixel

Split the M × N pixels into classes, usually foreground \(C_1\) and background \(C_2\). Edge detection looks for differences; region segmentation looks for similarity.

If we know each class's intensity distribution \(p_1(z), p_2(z)\), give a pixel with value \(z\) to the class with the larger likelihood \(p_i(z)\). This is maximum likelihood classification.

Thresholding

  • Global: one \(T\) for the whole image. \(g = 1\) if \(f > T\).
  • Multiple: \(T_1 < T_2\) give 3 classes.
  • Variable / local: \(T(x,y)\) from the local mean and std, e.g. \(T = m(x,y) + k\,\sigma(x,y)\). Handles uneven lighting.

Otsu's method: pick T automatically

Good split: each class is tight (small variances) and the classes are far apart. For threshold \(k\):

\[ P_1 = \sum_{i\le k} p_i,\quad m_1 = \frac{1}{P_1}\sum_{i\le k} i\,p_i,\quad m_2 = \frac{1}{P_2}\sum_{i>k} i\,p_i \] \[ \sigma_B^2 = P_1(m_1 - m_G)^2 + P_2(m_2-m_G)^2 = P_1P_2(m_1 - m_2)^2 \]
  • Total variance = between-class + within-class: \(\sigma_G^2 = \sigma_B^2 + \sigma_W^2\). \(\sigma_G^2\) is fixed.
  • So maximize \(\sigma_B^2\) ⇔ minimize \(\sigma_W^2 = P_1\sigma_1^2 + P_2\sigma_2^2\).
  • Try every \(k\), keep the best. Fast with running sums of \(P_1(k)\) and \(\sum i p_i\).
  • Separability \(\eta = \sigma_B^2/\sigma_G^2 \in [0,1]\).

Edge trick. If the object is tiny, its histogram peak is invisible. Run Otsu only on pixels near strong edges (high gradient or |Laplacian|). Then both classes are equally represented.

Multiple thresholds: maximize \(\sum_k P_k (m_k - m_G)^2\) over all choices of \(k_1 < k_2 < \dots\)

k-means clustering

Treat each pixel's value (or colour) as a point \(z_i\). Find \(k\) means minimizing the within-cluster sum of squares:

\[ \text{WCSS} = \sum_{i=1}^{n}\|z_i - m_{a_i}\|^2 \]
  1. Guess means \(m_1, \dots, m_k\).
  2. Assign each point to its nearest mean.
  3. Move each mean to the average of its points.
  4. Repeat 2–3 until the means stop moving.
  • k-means = maximum likelihood if clusters are Gaussians with equal variance (log-likelihood ∝ −WCSS).
  • For gray images with k = 2, k-means and Otsu minimize the same thing (WCSS ∝ \(\sigma_W^2\)). Otsu finds the global optimum by trying all k. k-means can get stuck in a local minimum, but it extends easily to colour and many clusters.

Superpixels with SLIC

k-means on position + colour: \(z_i = [x, y, r, g, b]\). Clusters become small compact patches that follow edges.

  1. Seed centres on a grid with spacing \(s\). Nudge each to the lowest-gradient pixel in its 3 × 3 neighbourhood (so seeds do not sit on edges).
  2. Assign each pixel to the nearest centre, searching only centres within a \(2s \times 2s\) window. (This makes it fast: \(O(N)\).)
  3. Update centres, repeat.
\[ D = \sqrt{(d_c/c)^2 + (d_s/s)^2} \]

\(d_c\) = colour distance, \(d_s\) = pixel distance. \(c\) trades off compactness vs. sticking to colour. Superpixels give a small over-segmentation to feed into k-means, graph cuts, etc.

Intelligent scissors

The user clicks a seed point. As the mouse moves, the tool draws the shortest path from seed to mouse through a graph of pixels (8 neighbours each). Dijkstra makes it fast.

Edge weights must be low along image edges:

\[ w(p,q) = \lambda_Z w_Z(q) + \lambda_G w_G(q) + \lambda_D w_D(p,q) \]
  • \(w_Z = 0\) if \(q\) is a Laplacian zero crossing (on an edge), else 1.
  • \(w_G\) small when \(\|\nabla f(q)\|\) is large.
  • \(w_D\) small when the step \(p\to q\) runs along the edge (perpendicular to both gradients), and the gradients agree. Smooth paths.

Exam-style practice

Histogram over levels 0–3: \(p = [0.4, 0.1, 0.1, 0.4]\). Find Otsu's threshold.
Answer

\(m_G = 0.1 + 0.2 + 1.2 = 1.5\).

k=0: P₁=.4, m₁=0, m₂=1.5/.6=2.5 → .24 × 6.25 = 1.5.

k=1: P₁=.5, m₁=.2, m₂=2.8 → .25 × 6.76 = 1.69.

k=2: P₁=.6, m₁=.3/.6=.5, m₂=3 → .24 × 6.25 = 1.5.

\(k = 1\): {0,1} vs {2,3}. (Symmetric histogram, symmetric answer.)

Give a case where k-means with k = 2 on intensity fails, but Otsu works.
Answer

Bad initialization: if both initial means start inside the same mode (e.g. both in the background), k-means can converge to splitting the background into two and lumping the object with one half. Otsu checks every threshold, so it always finds the global best.

Why does SLIC only search a \(2s\times 2s\) window?
Answer

Centres are about \(s\) apart, so a pixel's nearest centre must be within about \(s\) in each direction. Limiting the search makes each iteration \(O(N)\) instead of \(O(Nk)\), and keeps superpixels compact.

Cheat sheet · region segmentation

  • ML: pick class with max \(p_i(z)\)
  • Local T: \(m(x,y) + k\sigma(x,y)\)
  • \(P_1 = \sum_{i\le k}p_i\), \(m_1 = \frac{1}{P_1}\sum_{i\le k} i p_i\)
  • \(\sigma_B^2 = P_1P_2(m_1-m_2)^2\) → max over k
  • \(\sigma_G^2 = \sigma_B^2 + \sigma_W^2\); \(\eta = \sigma_B^2/\sigma_G^2\)
  • k-means: assign nearest → recompute means; local min
  • k-means(k=2, gray) ≡ Otsu objective; Otsu = global
  • SLIC: \([x,y,r,g,b]\), \(D = \sqrt{(d_c/c)^2+(d_s/s)^2}\), 2s×2s
  • Scissors: Dijkstra; cost low on zero-crossings, high gradient
